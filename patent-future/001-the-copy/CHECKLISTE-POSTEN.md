# Start von Patent Future: Checkliste

Alle Dateien liegen in diesem Ordner (`patent-future/001-the-copy/`).

## Tag 1: File 001 (ca. 18–20 Uhr)

1. YouTube Studio → **Erstellen → Videos hochladen** → `the-copy.mp4`
2. **Titel:** He Died 3 Years Ago. He Still Comes to Dinner.
3. **Beschreibung** aus `upload-text.txt` kopieren (der Textblock unten kommt automatisch aus den Standardwerten)
4. **Thumbnail:** `thumbnail.png` hochladen
5. **Playlist:** neue Playlist **„Patent Future Files“** anlegen und auswählen
6. **Zielgruppe:** Nein, nicht speziell für Kinder
7. **Mehr anzeigen:**
   - Veränderte oder synthetische Inhalte: **Ja**
   - Tags aus `upload-text.txt`
8. **Videoelemente → Untertitel hinzufügen:** Sprache Englisch → „Datei hochladen“ → „Mit Zeitangaben“ → `subtitles_en.srt`
9. **Videoelemente → Endbildschirm:** Vorlage „1 Video + Abonnieren“, Video = „Neuester Upload“, letzte **10 Sekunden**
10. **Sichtbarkeit:** Öffentlich (oder „Planen“ auf die Uhrzeit)
11. Sobald es online ist: **Kommentar** aus `upload-text.txt` schreiben und **anpinnen**
12. In der ersten Stunde auf Kommentare antworten, das hilft dem Video.
13. **Kanalseite:** Anpassung → Layout
    - „Für Besucher empfohlen“: File 001 auswählen
    - Abschnitte: Playlist „Patent Future Files“ hinzufügen (die Shorts-Reihe kommt an Tag 2 nach dem ersten Short dazu)

## Tag 2: Short (ca. 18–20 Uhr)

1. **Erstellen → Videos hochladen** → `short.mp4` (YouTube erkennt das Hochformat automatisch als Short)
2. Titel und Beschreibung aus `short-upload-text.txt`
3. **Ähnliches Video:** File 001 auswählen. Das ist der wichtigste Schritt, darüber kommen die Zuschauer zum ganzen Video.
4. Nicht für Kinder · Synthetische Inhalte: Ja · Playlist: Patent Future Files
5. Veröffentlichen

## Danach

- File 002 (Gedankenchip) folgt 3–4 Tage später, danach sein Short
- Nach 4 Wochen: Statistik ansehen und den Takt festlegen (2 oder 3 Folgen pro Woche)
